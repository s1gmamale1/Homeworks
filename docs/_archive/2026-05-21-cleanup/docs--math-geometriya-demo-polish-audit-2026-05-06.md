## Phase-by-phase risk for tomorrow

- **Gate quote / fact** — no math-specific blocker found this pass.
- **Preview / panels** — NAV-01/NAV-02 are demo blockers; geometry forces ~19 swipes today.
- **Flashcards** — FC-01/FC-02/FC-03/FC-04 affect every text-heavy or formula-only card. Worst case: `HW-20260505-006` shows ten flashcards of small top-aligned monochrome text — unmistakably "AI demo".
- **Adaptive Quiz / Boss** — AC-01 is critical. Geometry uses α / tg / ctg / ° heavily; algebra uses U+2212 minus. Many "correct" student answers will read as wrong.
- **Dark mode** — DM-01 is reachable on the very first preview screen if dark theme is on at start.
